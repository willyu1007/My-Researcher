  - emits control-plane input snapshot, workflow run, structured-output artifact, readiness gate, audit, and stable sample hash.

- Updated the local real-flow harness with deterministic mock LLM mode for end-to-end rehearsal:
  - resource sampling classification honors role targets and deterministic guardrails;
  - v1b ResearchSlice, TopicQuestion, and ValueAssessment structured outputs are generated locally;
  - `answerable_with_risk` produces and carries accepted-risk refs through the package path;
  - the harness still exercises real HTTP routes, Prisma repositories, control-plane artifacts, and live DB persistence.
- Provider LLM quality hardening from deep tests:
  - TopicQuestion formation now normalizes inherited falsification source refs when the provider copies a known `research_slice_boundary` id with the wrong prefix.
  - TopicQuestion formation now canonicalizes known inherited evidence refs by `ref_type + ref_id` when only `title_card_id` drifts.
  - Resource sampling now moves low-relevance target-role candidates (`topic_relevance < 0.7`) to `review`, preventing weak support/challenge/baseline/context items from entering selected samples.
- Provider sampling stability hardening from repeated real-LLM runs:
  - LLM classification is batched (`24` eligible candidates per structured-output call) to avoid single 100+ candidate requests timing out.
  - Workflow telemetry now aggregates batched LLM calls and preserves failed-call telemetry where available.
  - Deterministic role canonicalization now handles risk-heavy challenge, benchmark/assessment/comparison baseline, theory/background context, strong-title topic-method support, and broad foundation review.
  - Selected ordering now prioritizes deterministic source-text role signals over volatile LLM role scores/relevance/confidence.
  - The quality harness now separates provider failures from semantic drift, records workflow diagnostics for blocked runs, and treats selected role drift plus sample-hash drift as hard failures.
  - Selected-set construction now uses source-only deterministic pre-classification and deterministic per-role relevance floors. LLM output remains part of rationale, confidence, method families, telemetry, and audit artifacts, but LLM wording/relevance variation no longer changes selected identity when source evidence has a deterministic role.
  - Risk/baseline precedence was tightened after real-flow review: benchmark-first resources without strong adversarial/security/failure markers are canonicalized to `baseline`, while explicit attacks, poisoning, persistent-memory attacks, source-verification failures, and retrieval degradation remain `challenge`.
