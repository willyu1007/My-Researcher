## Do-not-repeat Summary
- Do not use `论文管理` as an unbounded backend owner; use precise internal domains.
- Do not let LLM memo, rationale, or board summary become evidence or citation.
- Do not run experiments outside a WorkOrder harness.
- Do not build writing UI before implementation dossier readiness exists.
- Do not let implementation feedback overwrite upstream topic-selection authority.
