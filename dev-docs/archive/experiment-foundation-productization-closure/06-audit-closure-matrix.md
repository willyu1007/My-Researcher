## Status vocabulary
- `open`: accepted review finding; no verified closure.
- `in-progress`: owning phase is implementing/verifying the closure.
- `blocked`: an explicit external decision/dependency prevents progress.
- `verified`: exit criterion has machine-readable evidence and required manual/usage evidence where applicable.
