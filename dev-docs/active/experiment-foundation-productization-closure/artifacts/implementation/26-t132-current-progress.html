产品化方向

  • Local-first 保持主路线 下载后由用户自行配置 OSS、对象存储或其他 provider，不强制购买托管云方案。
  • BYOC 是配置边界 产品提供 typed adapter、资源绑定、预检和安全 guard；用户掌握账号、费用和凭据。
  • 云执行是可选 capability 默认关闭；本地研究管理、谱系与审阅工作流不依赖云资源。
  • 科学证据仍需更高门槛 M7-L1 仅为 diagnostic-only；M7-L2 需要 OCI/content digest 和独立科学闭环授权。
