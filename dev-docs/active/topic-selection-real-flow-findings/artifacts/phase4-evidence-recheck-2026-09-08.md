# Phase 4：有界文献补查与最小配对基准

用途：为当前证据检查点提供可核查的补充审阅材料。本文是研究建议与任务验证证据，不是 EvidenceMap、覆盖判定、Human 决定或已执行的实验。产品的冻结包保持原样；最新操作状态以产品 API 与 `01-status.md` 为准。

## 判断

**建议先回环补强证据，再判断是否接受剩余风险。** 现有工作已经覆盖检索效用预测、不同检索器下的表现变化、校准与选择性回答。不能把这些组成部分本身作为新贡献。本轮没有找到直接验证下列完整协议的论文，但这只是有界检索结果，不是新颖性证明：固定问题、语料、生成器和原路由器，单独替换检索器，然后比较零样本迁移、简单阈值重调、小样本校准与固定基线回退。

当前候选问题应改成可证伪的诊断：**检索器替换后，冻结效用路由器是否出现有实际影响的失准；若出现，简单阈值重调是否已经足够？** 只有这个问题成立且简单方法不足，才值得研究更复杂的修复策略。这是建议的最小验证范围，尚未改写 TitleCard 或正式问题合同。

- 只用原论文和作者/数据维护者仓库支持结论。搜索摘要及聚合站仅作发现入口。没有检索所有数据库、所有语言或系统追踪所有引用；“未找到”只适用于本轮。

## 公开缓存的资格核查

`Know Before You Fetch` 的[固定仓库版本](https://github.com/dongzhe1/know-before-you-fetch/tree/d0cb4238b351345bef50ad4df70ea0c1f67e60bc)可访问，但这不等于当前文件是论文的真实配对输出。独立核查在该版本的两个 TriviaQA 表中各找到 200 行、10 个不同的标准化问题；176 个位置的问题不相同，同名问题也无法唯一配对。[环境样例脚本](https://raw.githubusercontent.com/dongzhe1/know-before-you-fetch/d0cb4238b351345bef50ad4df70ea0c1f67e60bc/scripts/make_sample_data.py)使用这 10 个问题随机生成 correctness 等字段；其 `--real` 分支使用真实问题，但仍模拟结果字段。

因此**不将这两份缓存作为真实检索器替换实验输入**。文件路径、字节数、hash 和配对检查见操作记录。这里判定的是本次检查的文件是否适配实验，不据此推断论文整体真伪，也没有验证其外部归档发布物。

## 最小配对基准草案

以下都是拟议设计，尚未执行、未注册实验资产，也不是 Human 已接受的阈值或成本。

### 单一干预与配对单位

- 首轮只做**同一静态语料上的 BM25 → 一个固定版本的稠密检索器**。生成器、解码、提示、查询集合、chunk、文档 ID、top-k 和上下文 token 上限保持不变。索引内容更新、查询分布变化、生成器变化都留到后续独立对照。
- 记录单位是唯一 `query_id`，以及同一问题的无检索答案、BM25 答案、稠密检索答案、各自正确性、检索文档 ID/分数、路由器分数、真实成本与配置指纹。无检索输出共用一次；无法验证同一问题/配置的旧表不进行推测性拼接。
- 原路由器参数与特征定义在源域冻结；只允许目标校准器及验证集选出的阈值按预声明方案变化。若需要换特征或重新训练路由器，单列为更强方法，不能称作纯校准。

### 数据与隔离

- 首选 [HotpotQA 官方 dev distractor](https://hotpotqa.github.io/)：公开文件约 44 MB，包含 7,405 个问题及答案、段落与支持事实；[维护者说明](https://github.com/hotpotqa/hotpot)区分数据 CC BY-SA 4.0 与代码 Apache 2.0。将候选段落按内容去重，构建一次共享池，禁止检索阶段按测试题的支持事实挑段落。它仍是由基准题目构建的受控语料，不是全 Wikipedia，也不证明未知文档泛化。未下载全量数据或构建索引；将来实际去重规模必须实测，不能照搬论文的 66,635。
- 两个后备选项：[NQ-Open](https://github.com/google-research-datasets/natural-questions/blob/master/nq_open/README.md)及 [FlashRAG](https://github.com/RUC-NLPIR/FlashRAG)可供更大静态 Wikipedia 复验，须区分原始与工具自定 splits；[KILT](https://github.com/facebookresearch/KILT)提供统一快照和 provenance，但语料约 34.76 GiB，官方测试答案不公开，起步更重。[BEIR NQ qrels](https://huggingface.co/datasets/BeIR/nq/blob/main/README.md)是检索相关性标签，不提供 `y0/yR`。本轮仅核查元数据/说明，FlashRAG 语料目录遇到 429，完整下载和运行均未验证。
- 第一对候选检索器为 BM25 与 [E5-small-v2](https://huggingface.co/intfloat/e5-small-v2)；按模型卡使用 query/passage 前缀。下载、revision 固定、许可物料清单和算力可用性在实验准入前核验，不从模型卡可访问推断本机可运行。
- 以问题分组拆分源训练、目标小样本拟合、目标阈值验证、最终评估；同一问题的三种答案始终同组，重复/近重复问题和共享泄漏风险显式检查。
- 成本估算用的小规模可行性提案：1,000 个问题，400 源训练、128 目标适配/验证、472 留出；目标标签总预算取 32/64/128 个嵌套问题。校准方法可用一半拟合、一半选阈值；纯阈值基线可使用整档标签选阈值。各方法共享相同总额度，内部划分按方法需要决定，不能额外提供免费监督。标签过少或类别不足时记为不可估计。这不是最终功效证明；若值得继续，再按最小可检测差异规划独立确认集（可先评估约 2,000 题的成本），不能把已看过的可行性集重命名为确认集。
- 原路由器可先用小型线性/逻辑模型建立可解释基线。路由特征若包含已检索文档或分数，必须计入那次检索；不能把检索后的判断包装成提前节省检索调用。

### 标签、校准和回退

- 主要 correctness 标签 `y0, yA, yB ∈ {0,1}` 来自同一个冻结的答案评分规则；有符号效用 `uR = yR - y0 ∈ {-1,0,1}`，显式保留检索有害的样本。F1 作为敏感性分析，不与二元 correctness 混用。
- 若路由器提供 gain/neutral/harm 三类概率，可报告三类 Brier：每题将三项概率与 one-hot 真值的平方差相加，再对问题取均值。只有标量效用输出时先报告 MSE，不能称作 Brier；若用单事件 Brier，必须分别说明 benefit 与 harm 事件，不能把有害和中性合并后声称风险已校准。最终指标接口在实验准入前明确。
- 首轮回退含义是**路由器弃权后采用预先选定的固定策略**，建议先用 always-retrieve 作为可审计基线；这不代表系统拒绝回答，也不假定该基线必然更安全。正式确认前可替换为另一明确基线，但不能看测试答案后逐题选择。
- 分开报告 router coverage（多少问题由适配后的冻结路由器决策）与 answer coverage（多少问题实际返回答案）。若保留此前讨论的 ≥90% router coverage，就限制回退最多 10%；另行测试最终拒答时必须单列协议，不能靠降低回答覆盖制造改善。

### 最小对照与识别条件

| 对照 | 解决的判断 |
|---|---|
| 原路由器与原阈值，直接迁移 | 问题是否确实出现 |
| 冻结分数，用整档目标标签额度重调阈值 | 最便宜的修复是否已足够 |
| 同一分数的小样本单调校准，无回退 | 概率质量是否改善；不能预设排序改善 |
| 同一校准方案 + 固定基线回退 | 回退是否带来独立收益，且没有突破预算或覆盖约束 |
| 未校准分数 + 同一回退规则；相同回退率的随机回退 | 区分校准、回退选择和仅增加回退次数的贡献 |
| 无标签置信/检索分数规则，以及 always/never-retrieve | 复杂度与监督成本是否必要 |
| 相同目标标签预算从头训练的小路由器 | 复用冻结原模型是否具有标签效率优势 |

严格递增的校准变换保留分数排序：在相同精确 top-k 配额、相同 tie-break 下，校准前后选中集合相同。对自由选择的阈值，严格递增校准与原分数阈值属于同一策略族；非严格递增映射的平坦区可能减少可实现的切分，固定 tie-break 也不自动恢复严格等价，不能把 tie 变化当作新排序能力。因此校准收益应首先在概率质量、部署阈值迁移或跨动作风险可比性上检验。若扩展为额外信号/回退而改变选择，必须将收益归属到那项变化。

### 指标与停止规则

- 并列报告整体 EM/F1、检索有害率、相对固定基线的逐题损失、benefit/harm 比例、Brier、排序指标、实际检索率、router/answer coverage、生成与检索 token/调用/延迟。
- 精确预算排序曲线仅作诊断；可部署策略必须在验证集选阈值，然后原样评估留出集并报告真实预算偏差。不能用测试标签寻找最佳工作点。
- 各策略使用相同问题做配对差值与区间；样本不足以区分预声明的实用差异时，结论是未决。实际意义阈值、质量容忍度与功效检查须在实验执行前确定。
- 可行性阶段没有明显退化信号时暂不升级实验，低功效结果仍为未决；只有足够精度的区间排除了预声明的实用退化，才判定该条件缺少值得修复的问题；如果阈值重调即可解决，保留简单方案；如果回退只是牺牲回答覆盖、突破成本或比固定基线更有害，不接受改善结论；如果相同标注预算从头训练同样有效，不宣称迁移方法的标签优势。
- 成本草算：N 个问题、一名固定生成器、两种检索器最多需要 `3N` 份基础答案和 `2N` 次检索结果；模型已有缓存可核验复用。批处理会改变 API 调用数；索引/嵌入、校准、评分审计与额外特征成本另计。没有推理报价、硬件吞吐或付费执行授权，本轮不启动这些工作。
- 目标标签预算公平不等于总训练成本相同：历史源训练标签/算力也须单列。任何无监督标签生成器、额外 probe、重试和回退推理均计费计次；本轮没有测量这些成本。

## 当前审阅动作

建议对原证据检查点选择 `loopback`，目标 `evidence_landscape`：保留两条缺失覆盖义务，先纳入本轮可核查的新近反例，明确最小替换协议与回退定义，再生成新的可审阅证据包。这个动作不接受缺口、不决定最终研究价值，也不授权实验/provider 执行。
