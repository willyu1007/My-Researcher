# v1a N1-N9 Gap Audit

## Scope
Audit target: T-112 v1a runtime/context/cache/compression coverage across `topic-selection.v1a` N1-N9.

This audit separates three node classes:
- deterministic context producers: N1-N4;
- LLM-backed runtime slots: N5-N8;
- deterministic terminal publish boundary: N9.

The current v1a production goal is not to force every node through identical LLM runtime behavior. The goal is that every node either produces ref/hash-stable context for downstream LLM use, or consumes LLM context through the shared runtime without bypassing deterministic gates, replay identity, or authority boundaries.
